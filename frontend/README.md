# Image to Text Web

Modern, responsive, and open-source React frontend for an Image-to-Text OCR web application.

## Features

- Drag and Drop Upload
- Multiple Image Support
- Clipboard Paste
- Image URL Upload
- OCR Processing
- Download Extracted Text
- Responsive Design

## Tech Stack

- React
- Vite
- JavaScript
- CSS

## Installation

```bash
npm install
npm run dev
```
